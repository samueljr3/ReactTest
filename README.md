# Paradise Nursery

Paradise Nursery is an online plant shop built with React and Redux Toolkit.
Users can browse houseplants by category, add them to a shopping cart,
change quantities, delete items, and see the total cost.

## Features
- Landing page with a "Get Started" button
- Plant listing page with 3 categories (6 plants each)
- Navbar with Home, Plants and Cart links, plus a live cart count
- Shopping cart with quantity controls, delete buttons and totals
- Checkout button (shows "Coming Soon")

## Run the project
```
npm install
npm install @reduxjs/toolkit react-redux
npm run dev
```
